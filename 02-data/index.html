How to check any of it. Every table names its source in a source_id and a page. Run python 03-harness/fetch_sources.py to rebuild the document vault from the public record; any file whose checksum does not match is rejected rather than kept. Then python 03-harness/check.py re-renders every page from these tables and fails if one has drifted.
